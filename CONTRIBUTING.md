# 🤝 Contributing

Thanks for your interest! Here's how to help.

## 🎯 Ways to Contribute

- 🐛 Report bugs
- ✨ Suggest features
- 📝 Improve docs
- 🔧 Fix code
- 🧪 Write tests

## 🚀 Getting Started

### Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/mhzaly-domain-recon.git
cd mhzaly-domain-recon
```

### Create Branch
```bash
git checkout -b feature/your-feature-name
```

### Make Changes & Test
```bash
streamlit run domain_recon_app.py
```

### Push & Create PR
```bash
git push origin feature/your-feature-name
```
