# ⚡ Quick Start Guide

## 🎯 Get Running in 5 Minutes

### Step 1: Install
```bash
pip install -r requirements.txt
```

### Step 2: Run
```bash
streamlit run domain_recon_app.py
```

### Step 3: Open Browser
Go to `http://localhost:8501`

### Step 4: Test
Enter `google.com` and click "🚀 Analyze"

## 🆘 Troubleshooting

| Issue | Solution |
|-------|----------|
| ModuleNotFoundError | `pip install -r requirements.txt` |
| Port 8501 in use | `streamlit run ... --server.port 8502` |
| Subfinder not found | It's optional; app works without it |
| API key error | Check format starts with `sk-ant-` |
